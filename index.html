五專資工三甲Javascript 程式設計課程


個人資料 N*N 水管遊戲 計算機


在這次的學習過程中，我接觸到了 HTML、CSS、JavaScript 和 React，對前端開發的整體流程有了更清楚的認識。
而HTML 和 CSS 是決定網頁的結構與視覺風格。透過調整版面配置、字型與配色，能讓一個原本空白的網站頁面變得有內容和具有吸引力。
進入 JavaScript 後，發現可以讓網頁動起來，不再只是靜態畫面，像是可以點擊按鈕、表單驗證或圖片輪播這些功能，讓我對網頁互動有了更深的了解。
而 React 則是這段學習旅程中最具挑戰但也最有趣的部分，它利用元件化的概念，將複雜的網頁拆解成獨立小單位，方便管理與重複使用，大幅提升開發效率與維護彈性。
雖然在實作過程中遇到許多錯誤與困難，但透過不斷查詢資料、詢問與調整，逐漸掌握每個技術的應用方式，也更清楚前端開發的邏輯與架構。
未來希望能將這些學到的程式技術運用在自己的專案上，創作出屬於自己的網站。
